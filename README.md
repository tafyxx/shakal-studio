# 👾 Shakal Studio v9.0 Motion

> **Ультимативная студия глитч-эффектов, шакализации видео до 240 FPS, разрушения звука и скрытых пранков для Discord.**

---

## ✨ Основные возможности

### 📸 Фото и скриншоты
- **Ультра-шакаливание**: Экстремальное сжатие JPEG (до 1%), пикселизация, Deep-Fry выжигание, овершарп.
- **Аналоговые и цифровые искажения**: CRT сканлайны кинескопа, сдвиг цветовых каналов RGB, дизеринг Retro, разрывы развертки, виньетка, jitter (дрожание строк), шум видеоголовки VHS.
- **Аномалии экрана**: Разрывы матрицы, битые пиксели, водяной знак активации Windows, шлейф курсоров мыши, каскад окон XP, синий экран BSOD.
- **Рекламный спам**: Наложение хаотичных баннеров и всплывающих окон поверх снимка.

### 🎥 Видео до 240 FPS и Шакальный Звук
- **Высокоскоростная запись**: Настройка частоты кадров от 15 до **240 FPS** с адаптивным энкодером OpenCV / FFmpeg.
- **Звуковой процессор шакаливания**:
  - **Ear-Rape перегрузка** и жесткий цифровой клиппинг.
  - **Бас-буст** с резонансом нижних частот.
  - **Резкие пропадания звука** (дропауты) и случайные обрывы сигнала.
  - **Bitcrush**: понижение разрядности и частоты дискретизации до эффекта винтажного модема или сломанной рации.
  - **Скримеры**: автоматическое подмешивание оглушительных криков и визуальных помех в видео.

### 🎭 Режим «Дискорд Пранк» и трансляция как «Экран 2»
- **Отдельный экран в Discord**: Проекция на второй монитор без рамок. В Discord при включении демонстрации выбирается не окно программы, а нативный **«Экран 2»**, создавая эффект реального сбоя системы собеседника.
- **Абсолютная невидимость**: Технология `WDA_EXCLUDEFROMCAPTURE` делает окно самой студии невидимым для захвата Discord и OBS — вы можете крутить ползунки прямо во время демонстрации!
- **Поддержка Virtual Display Driver**: Подробная встроенная инструкция по созданию виртуального второго дисплея на ПК с одним монитором.

### 🎨 Минималистичный Motion Dark интерфейс
- **Компактные размеры**: Оптимизированный интерфейс `1020x640`, не перекрывающий рабочий стол.
- **Интерактивные подсказки**: Нижняя статусная панель мгновенно выводит подробное описание назначения любого ползунка, тумблера или кнопки при наведении мыши.
- **Чистый дизайн**: Строгая палитра Motion Slate без кислотного неона и лишних визуальных помех.

## 🚀 Быстрый старт

### Требования
- **Windows 10 / 11** (64-bit)
- **Python 3.10+** (с галочкой *Add Python to PATH* при установке)

### Запуск в 1 клик
Просто дважды кликните по файлу **`glitcch.bat`**.  
Скрипт автоматически проверит и установит все недостающие библиотеки (`pillow`, `opencv-python`, `numpy`, `sounddevice`, `scipy`, `imageio-ffmpeg`) и запустит студию.

### Ручная установка
```bash
# Клонируйте репозиторий
git clone https://github.com/your-username/shakal-studio.git
cd shakal-studio

# Установите зависимости
pip install -r requirements.txt

# Запустите студию
python -x glitcch.bat
```

## 📺 Настройка «Экрана 2» для Discord Пранка

1. Если у вас **два физических монитора**:
   - Нажмите кнопку **«Проецировать на Экран 2»**.
   - В Discord перейдите в **Демонстрация экрана ➔ Вкладка «Экраны» ➔ Экран 2**.
   - Собеседники видят полноэкранный глитч, а ваше рабочее окно студии остается на Экране 1 и скрыто от захвата.

2. Если у вас **один монитор**:
   - Нажмите кнопку **«Инструкция: Экран 2 для Дискорда»** во вкладке «Дискорд Пранк».
   - Установите бесплатный драйвер виртуального дисплея [Virtual Display Driver (IddSampleDriver)](https://github.com/itsmikethetech/Virtual-Display-Driver).
   - Windows создаст виртуальный второй дисплей, который мгновенно появится в списке мониторов Shakal Studio и во вкладке экранов Discord!

## 🛠 Стек технологий
- **GUI**: Python Tkinter с кастомным рендерингом Motion Dark.
- **Графика и эффекты**: Pillow (PIL), OpenCV, NumPy.
- **Аудио**: SoundDevice, SciPy (WAV DSP), генерация шумов и фильтрация частот в реальном времени.
- **Видео и кодеки**: ImageIO-FFmpeg, OpenCV VideoWriter.
- **Интеграция с Windows API**: `ctypes` (`user32.dll`, `dwmapi.dll` — `WDA_EXCLUDEFROMCAPTURE`, `EnumDisplayMonitors`).
