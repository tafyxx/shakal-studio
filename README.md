# 👾 Shakal Studio v9.0 Motion

> **Ультимативная студия глитч-эффектов, шакализации видео до 240 FPS, разрушения звука, реалистичных сбоев системы для проверок на читы и стримов в Discord.**

---

## ✨ Основные возможности

### 📸 Фото и скриншоты
- **Ультра-шакаливание**: Выбор качества в **P-разрешении** от 72p и 144p (дикий шакал) до 1080p (Full HD), экстремальное сжатие JPEG, овершарп, Deep-Fry.
- **Аналоговые и цифровые искажения**: CRT сканлайны, сдвиг RGB-каналов, дизеринг, разрывы развертки, виньетка, jitter (дрожание строк), шум видеоголовки VHS.
- **Аномалии экрана**: Разрывы матрицы, битые пиксели, водяной знак активации Windows, шлейф курсоров мыши, каскад окон XP, синий экран BSOD.
- **Рекламный спам**: Наложение хаотичных баннеров и всплывающих окон поверх снимка.

### 🎥 Видео до 240 FPS и Шакальный Звук
- **Высокоскоростная запись**: Настройка частоты кадров от 15 до **240 FPS** с аппаратным энкодером OpenCV / FFmpeg.
- **Звуковой процессор шакаливания**:
  - **Ear-Rape перегрузка** и жесткий цифровой клиппинг.
  - **Бас-буст** с глубоким резонансом нижних частот.
  - **Резкие пропадания звука** (дропауты) и случайные обрывы сигнала.
  - **Bitcrush**: винтажный модем и сломанная рация.
  - **DPC Freeze Buzzer**: аппаратное зацикливание звука (ТР-Р-Р-Р) при симуляции зависания ПК.
  - **Скримеры**: подмешивание оглушительных криков и визуальных помех.

### 🛡️ Приколы для Проверок на Читы (Discord Cheat-Check)
Специальный набор аутентичных сбоев ПК для вызова на проверку в Discord (Rust, Minecraft, CS2 и др.):
- **Залагивание кадров и залипание окон**: При открытии новых папок, диспетчера задач или AnyDesk старые окна не закрываются и зависают слоями на экране!
- **Слет видеодрайвера TDR**: Экран на 0.7 сек гаснет в темноту, звучит аппаратный сбой и в углу всплывает настоящее системное уведомление Windows:  
  *«Видеодрайвер NVIDIA Windows Kernel Mode Driver перестал отвечать и был успешно восстановлен»*.
- **Сбой памяти Explorer**: Настоящее диалоговое окно ошибки Windows:  
  *«explorer.exe - Ошибка приложения: Память не может быть read (0x00007FF63B48)»*.
- **Артефакты видеопамяти GPU**: Цветные шахматные квадраты и битые блоки отвала видеочипа.
- **Зависание звука**: Металлический треск зависшего аудиодрайвера.

### 🎭 Стрим в Discord БЕЗ виртуального монитора
Никаких сторонних драйверов или сложных установок — все работает сразу:
1. **Режим «Оверлей на Экран 1» (Сквозной пранк)**:  
   Активируется кнопкой или клавишей **F11**. На рабочем столе включается прозрачный сквозной слой, сквозь который свободно кликает мышь (папки, игры, браузер работают штатно). В Discord стримите **«Весь экран ➔ Экран 1»** — зрители видят все глитчи, а сама студия **полностью скрыта от захвата** благодаря защите `WDA_EXCLUDEFROMCAPTURE`!
2. **Режим «Окно для стрима» (Вкладка Приложения)**:  
   Создает чистое окно **«Рабочий стол Windows»**, которое сразу отображается в Discord во вкладке «Приложения» и транслирует рабочий стол со всеми эффектами в 60 FPS.
3. **Режим «Экран 2»**:  
   Для обладателей двух физических мониторов — мгновенный полноэкранный вывод на второй дисплей.

### 🎨 Минималистичный Motion Dark интерфейс
- **Компактные размеры**: `1020x640` — не загораживает экран и не мешает проверке.
- **Интерактивные подсказки**: Нижняя панель мгновенно выводит описание любой настройки при наведении мыши.
- **Качество в 'p'**: Четкий контраст качества — от 72p / 144p до 1080p без запутанных процентов.
- **Строгий стиль**: Без ядовитого неона и псевдо-стекла.

## 🚀 Быстрый старт

### Требования
- **Windows 10 / 11** (64-bit)
- **Python 3.10+** (с галочкой *Add Python to PATH* при установке)

### Запуск в 1 клик
Дважды кликните по файлу **`glitcch.bat`**.  
Скрипт сам проверит библиотеки, доустановит недостающие и откроет студию.

### Ручная установка
```bash
# Клонируйте репозиторий
git clone https://github.com/your-username/shakal-studio.git
cd shakal-studio

# Установите зависимости
pip install -r requirements.txt

# Запустите студию
python -x glitcch.bat
```

## 🛠 Стек технологий
- **GUI**: Python Tkinter с минималистичным рендерингом Motion Dark.
- **Графика и эффекты**: Pillow (PIL), OpenCV, NumPy.
- **Аудио DSP**: SoundDevice, SciPy (WAV), синтез частот и DPC-freeze в реальном времени.
- **Видеозахват и кодеки**: ImageIO-FFmpeg, OpenCV VideoWriter.
- **Windows API**: `ctypes` (`user32.dll`, `dwmapi.dll` — `WDA_EXCLUDEFROMCAPTURE`, `WS_EX_TRANSPARENT`, `WS_EX_LAYERED`).
